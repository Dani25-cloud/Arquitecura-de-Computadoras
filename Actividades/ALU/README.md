Esta actividad busca que se haga un módulo que conforme a la ALU, por ahora tendrá
solo dos entradasde 16 bits cada una y una salida para cada operación que se
implemente. Para todas las operaciones aritméticas, realizar la operación de forma
comportamental.
Parte de la introducción de su reporte es una pequeña investigación sobre los rasgos
generales de la ALU.
Desde el punto de vista de Verilog la intención de esta actividad es que se tenga el
módulo de ALU. Se realizarán suma, resta, multiplicación, división, and, or,
corrimiento de 1 bit a la izquierda, xor.
